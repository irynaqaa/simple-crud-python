# Test Suite

This directory contains the test suite for the web application using Robot Framework.

## Running Tests

To run the tests, execute the following command:

```sh
sh run_tests.sh
```

## Test Cases

- **test_login.robot**: Contains test cases for login functionality.
- **test_form.robot**: Contains test cases for form submissions.
- **test_data.robot**: Contains data-driven tests using external data sources.
